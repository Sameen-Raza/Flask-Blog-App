# My Personal Blog (Flask Project)

This is a simple blog web application built using Python and Flask.  
It includes user authentication, post creation/editing, and a SQLite database.

## Features

- Register / Login / Logout
- Create, edit, delete blog posts
- Each post has an author and timestamp
- User authentication using Flask-Login

## Installation

```bash
git clone https://github.com/Sameen-Raza/Flask-Blog-App.git
cd myblog
